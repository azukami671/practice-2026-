## 2. Создание сайта

### Структура файлов

В папке `site/` организована следующая структура файлов:

```text
site/
├── index.html          — главная страница
├── about.html          — страница «О проекте»
├── members.html        — страница «Участники»
├── journal.html        — страница «Журнал»
├── resources.html      — страница «Ресурсы»
└── css/
    ├── base.css        — общие стили для всех страниц
    ├── style.css       — стили главной страницы
    ├── about.css       — стили страницы «О проекте»
    ├── members.css     — стили страницы «Участники»
    ├── journal.css     — стили страницы «Журнал»
    └── resources.css   — стили страницы «Ресурсы»
```

CSS намеренно разделён на несколько файлов, чтобы каждая страница подключала только нужные стили — это упрощает навигацию по коду и дальнейшую поддержку проекта.

### Главная страница (`index.html`)

*Ответственный: Ким Илья Васильевич*

Главная страница состоит из двух секций.

#### Hero-секция

Первый экран, который видит пользователь. Включает:

- Badge с подписью «Геолокационные напоминания»
- Крупный заголовок «Не забудь.»
- Краткое описание идеи проекта
- Кнопку «Узнать больше», ведущую на страницу «О проекте»

Реализована анимация последовательного появления элементов при загрузке страницы — каждый элемент появляется с задержкой через `transition-delay`, что создаёт эффект плавного «разворачивания» страницы.

#### Секция возможностей

Три карточки с ключевыми функциями приложения:

| Карточка | Описание |
|---|---|
| 📍 Геозоны | Напоминание срабатывает при входе в нужную зону |
| 🎙️ Голосовой ввод | Задача создаётся голосовой командой |
| 📡 Офлайн-режим | Работает без интернета, карты кешируются |

При наведении карточки поднимаются вверх, подсвечиваются синей рамкой, иконка увеличивается и поворачивается.

### Страница «О проекте» (`about.html`)

*Ответственные: Ким Илья Васильевич, Темченко Софья Игоревна*

Страница разбита на четыре смысловых блока.

#### Карточки проблема / решение / аудитория

Три карточки описывают:

- **Проблему** — статичные напоминания не привязаны к месту
- **Решение** — геолокационные уведомления в нужный момент
- **Целевую аудиторию** — активные люди, много перемещающиеся по городу

При наведении карточка поднимается и сверху появляется светящаяся синяя полоска.

#### Как это работает

Пошаговая схема из трёх шагов со стрелками между ними:

1. **Создайте напоминание** — голосом или текстом, с привязкой к месту
2. **Приложение следит** — геозона работает в фоне, даже без интернета
3. **Получите уведомление** — мгновенно при входе в зону

При скролле до секции запускается анимация — шаги и стрелки последовательно подсвечиваются (glow-эффект), визуально показывая процесс работы приложения.

#### Технологии

| Технология | Назначение |
|---|---|
| 📱 Flutter | Кроссплатформенная разработка (Android/iOS) |
| 🗺️ 2ГИС / Яндекс.Карты | Геолокация и отображение карт |
| 📡 Geofencing API | Отслеживание входа в геозоны |
| ☁️ VK Cloud | Облачная инфраструктура |

## 3. Дизайн и стилистика

*Ответственная: Темченко Софья Игоревна*

Для сайта выбрана тёмная цветовая схема:

| Элемент | Цвет |
|---|---|
| Фон страницы | `#0f0f0f` |
| Поверхности карточек | `#1a1a1a` |
| Акцентный цвет | `#4f9eff` |
| Основной текст | `#f0f0f0` |
| Второстепенный текст | `#aaa` |

Все анимации реализованы через `IntersectionObserver` — элементы анимируются только когда попадают в область видимости при скролле, что выглядит естественно и не нагружает браузер при загрузке страницы.
